Diccionario Git Interactivo

Aprendiendo a trabajar con ramas

git init

Inicializa un nuevo repositorio local en la carpeta actual.

git clone

Descarga una copia exacta de un repositorio remoto.

git add

Prepara los cambios (staging) para ser incluidos en el próximo commit.

git status

Muestra cambios pendientes y la rama activa.

git commit -m "mensaje"

Guarda los cambios preparados en un commit.

git branch

Lista las ramas locales; el asterisco identifica la actual.

git checkout -b dev

Crea la rama dev y se cambia a ella.

git checkout main

Vuelve a main, la rama principal de este repositorio.

git merge --no-ff dev

Integra dev en la rama actual y conserva un commit de integración.

git push -u origin dev

Sube dev al remoto y configura su seguimiento.

git log --oneline --graph --all

Muestra el historial y las ramas en forma de gráfico.
